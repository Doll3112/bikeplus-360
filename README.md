Developed an end-to-end Bike Store Sales Analytics project using Excel, SQL, Python and Power BI.
Cleaned and prepared bike store data for accurate analysis.
Designed a relational database and performed SQL-based business analysis.
Analysed sales, products, customers, stores, staff and inventory.
Used Python and Pandas for exploratory data analysis.
Performed RFM analysis to understand customer purchasing behaviour.
Segmented customers based on their purchasing patterns.
Identified top-performing products and low-stock products.
Created an interactive Power BI dashboard with KPIs, charts, slicers and navigation buttons.
Generated business insights to support data-driven decision-making.
